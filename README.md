# SurveyQuest · CSURV2210 Higher Surveying

A gamified study app: five worlds that chart an island (tacheometry, mapping, control surveys, hydrography, route curves) plus an optional sixth, the Earthworks Frontier.

Open `index.html` (or the GitHub Pages site). Progress is saved in your browser only.

World 6 uses standard textbook content for the mass diagram, GPS and Simpson's rule; check it against your lecturer's notes.
